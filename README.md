# 📈 Leads Tracker Extension

**Leads Tracker Extension** is a lightweight and efficient browser extension designed to help users track and manage their sales leads and prospects directly from their browser. Whether you're in sales, marketing, or freelancing, this tool simplifies the lead management process and keeps you organized on the go.

## 🚀 Features

- ✅ Add new leads with ease
- 📝 Edit and update existing leads
- 👁️ View all your saved leads in one place
- 🔒 Data stored locally for privacy and offline access
- 🧩 Seamless browser integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chrome Extension APIs
